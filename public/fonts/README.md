# Fontes do jogo

- `caveat-latin.woff2`: Caveat (Impallari Type), variável 500–700, subconjunto latino. Licença SIL Open Font License 1.1. Usada na letra do caderno do Lemos no depoimento.
- `permanent-marker-latin.woff2`: Permanent Marker (Font Diner), subconjunto latino. Licença Apache 2.0. Caneta das etiquetas e perguntas do quadro do caso.
- `special-elite-latin.woff2`: Special Elite (Astigmatic), subconjunto latino. Licença Apache 2.0. Máquina de escrever das fichas do quadro do caso.
- `cormorant-garamond-italic-600-latin.woff2`: Cormorant Garamond (Christian Thalmann), itálico 600, subconjunto latino. Licença SIL Open Font License 1.1. Títulos do HUD (nome da sala, descobertas, caderneta).
- `jost-latin.woff2`: Jost (Owen Earl), variável 300–500, subconjunto latino. Licença SIL Open Font License 1.1. Textos finos do HUD.
